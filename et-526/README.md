# ET 526 visual evidence

Source/assets: [bdbd27cb87038a6929e7b913c871db442f6c98ca](https://github.com/cmilatinov/calyx-rust/commit/bdbd27cb87038a6929e7b913c871db442f6c98ca). Captured on 2026-11-04 in America/Toronto (2026-11-05 UTC), Windows, pinned nightly 2026-10-22, Blender 4.0, through `calyx_ctl`. The commands ran before committing; this revision contains the final source and generated assets exercised.

The 15 gallery images use the ET 526 editor and sandbox. The three arena images use the unchanged editor from [ET 515 revision 8e50ac8](https://github.com/cmilatinov/calyx-rust/commit/8e50ac817cec9fae6c0de022000f5befa9d5ce6b) with the ET 526 sandbox assembly explicitly rebuilt from the source revision above. These are integration evidence for accurate off-centre pointer mapping; ET 526 does not change editor pointer mapping. ET 515 and ET 519 subsequently merged into main; the ET 526 branch took them in after these captures, without changing these model/gameplay assets. A standalone ET 526 probe reproduced the existing pointer mapping error (27.44 px vertically), while its firing/base/head checks passed. That diagnostic attempt is excluded from this published set.

Each temporary gallery copies the corresponding authored lighting/post-process rig from `sandbox/assets/lookdev/tank_direction.cxscene`. Far uses height 34 m, back offset 13.7 m, pitch 68 degrees and horizontal FOV 64 degrees. Close-ups retain that pitch/FOV, move the camera 4 m above each model's centre and adjust the back offset to frame it. The gallery tests both terrain roles: grass/sand, sand/packed earth, and blue slate/moon dust. Reticles cast no shadows and use `outline_style = 0`.

Arena captures preserve the arena layout and gameplay while applying each map's lighting and generated-prop materials in temporary scenes. The tank was moved to (8, 0, 8); the Sentry's projectile speed was temporarily reduced from 16 to 4 m/s to keep a shell visible. Gameplay camera framing remains Far. The injected cursor is at (0.56, 0.65) in the Game image. The frames show the visible ground reticle and a Sentry shell in flight. These temporary scene/component edits were not saved to the shipped arena.

The [Sunny](sunny_aim.json), [Sunbaked](sunbaked_aim.json), and [Moonlit](moonlit_aim.json) results record world transforms, current head reference, unchanged base, live round count, image dimensions and projected cursor error for the reticle root at the ground aim point. The largest absolute axis error for that point is 0.0114 px; the rendered ring sits slightly above it to avoid ground z-fighting. All three integration runs reported `assemblies_loaded = true`, exposed the current `ComponentSentry.head`, turned the head without turning the gameplay root, and retained the root as each shell's shooter.

Both final editor logs contain startup, assembly registration, asset/scene and remote-control events. Each has 0 errors, 0 TypeId/assembly mismatches and 0 dropped-component reports. Each has two existing startup warnings about initial 1x1 render textures before the first panel size is available. The known debug-editor stack overflow (#514) was handled only in built executables: the ET 526 editor used a 32 MiB stack reserve; the existing ET 515 editor used 16 MiB. No engine/editor source workaround was added. Logs and command traces are retained in the local ET 526 evidence folder.

Validation: the implementation passed `agentic local validate` (format, workspace clippy and workspace tests) before final visual refinements. Final-tree validation is recorded on the PR. After the visual correction that separates the barrel's lid/rim/drum top surfaces, `cargo test -p calyx_model_gen` passed 52 tests with 2 Blender tests ignored; actual Blender generation and mesh validation were run for the 29 part meshes, then rerun for the corrected barrel. Tests cover stable prefab/material/mesh references, parent hierarchy, actual linked Sentry references, barrel top separation, reticle openings/outline/shadows, Sentry gameplay/shooter/shell geometry, and independent player-prefab reticle remapping.
