# Moonlit kit and asymmetric tree evidence

Source revision `1fb27658e046d9053ee44945d471cefd09c1b3ce`, merging #525 (`2d62a9a`).

35 actual Calyx game-view captures at 2062 x 932, controlled hands-free through the `calyx_ctl` protocol. All three palettes have fresh Far gallery and repeated-join pen views. Three updated trees have unequal offset crowns, visible notches, leaning forked trunks and irregular roots. Approved day materials are unchanged. Moonlit adds all 23 generated prefabs and 25 role materials using the authored night reference.

Far views use the saved camera and each map's original rig. All seven Moonlit rig objects match #525 exactly: moon 7, sky 1, bloom 4.5 / threshold 2.5 / knee 0.1 / radius 6. Lantern uses sodium emission 4; night pickups use 1.2 for bounded halos.

Close-ups isolate actual generated prefabs with temporary ambient inspection fill 0.65. This fill and the inspection camera/visibility were never saved. The cached compatible debug editor from ct266 retained the binary-only 16 MiB stack reserve workaround for #514. It reported assemblies loaded, then shut down after capture.
