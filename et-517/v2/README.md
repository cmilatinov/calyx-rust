# Concept-sheet arena kit evidence

Asset revision: `13473ad` (PR #520), including current main through `72dd4a8`.

Actual Calyx editor game-view captures, controlled hands-free through `calyx_ctl`'s JSON protocol. The cached compatible debug editor from `G:/ct266/target` was reused without rebuilding; its executable-only 16 MiB stack reserve workaround for #514 was retained. Engine source is unchanged by this model kit.

The four Far images use the saved scene cameras and original map lighting/post-processing, with no inspection fill. The gallery lays out all 23 models; the pen demonstrates repeated continuous wall joins and kit pieces beside the retained player tanks.

The 46 close-ups isolate each actual generated prefab, preserve its full silhouette, and add temporary ambient inspection fill at intensity 0.65 to expose undersides and assembly details. That fill, isolation, and close-up camera pose were never saved into source assets. Both sessions reported assemblies loaded; the editors were shut down after capture.

`concept-sheet.png` is the agreed reference. Compare model construction/silhouettes/material breaks; terrain tiles and replacing Tank_002 are outside this kit.
